# IA para Gestorías

## Objetivo
Reducir el tiempo que una gestoría dedica a redactar escritos repetitivos.

## Cliente
Pequeñas gestorías españolas de 1 a 10 empleados.

## Problema
Pierden tiempo redactando documentos administrativos similares de forma recurrente.

## Solución
Una aplicación sencilla donde el usuario completa un formulario y la IA genera un borrador del escrito listo para revisar, editar y utilizar.

## MVP inicial
Generador asistido de escritos administrativos repetitivos, empezando por un único tipo de documento para validar el flujo antes de ampliar funcionalidades.

## Modelo de negocio
Suscripción mensual SaaS.

## Principios del producto
- Uso sencillo y rápido.
- Revisión humana obligatoria antes de utilizar cualquier documento generado.
- Automatizar al máximo la generación del borrador.
- Mantener costes y soporte bajos.
- Ampliar tipos de documentos únicamente después de validar demanda real.
